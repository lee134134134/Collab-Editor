# 组件规范

## 书写形式（NON-NEGOTIABLE）

- 函数组件 + TypeScript，禁止 class 组件。
- 文件 PascalCase（`CommentPanel.tsx`），页面入口可 `index.tsx` / `editor.tsx`。
- 组件内部状态用 `useState` / `useRef` / `useEffect`；跨页共享放 Umi `@@initialState`。
- 副作用必须清理（事件监听、定时器、Yjs provider / Y.Doc 的 `destroy`）。
- React 19 StrictMode 下 effect 会双执行：创建资源前判断是否已存在、卸载时完整释放。

## Props 与事件（NON-NEGOTIABLE）

- 用 `interface XxxProps` 显式声明 Props；可选字段用 `?`。
- 事件处理函数以 `handleXxx` / `onXxx` 命名。
- 禁止子组件直接修改 Props；需要回传用回调。
- 单向数据流：父传子 Props，子传父回调；不要用全局状态中转本可 Props 解决的数据。

## 组件归属

| 层级 | 判定 | 位置 |
|---|---|---|
| 页面组件 | 路由直接渲染 | `pages/docs/index.tsx`、`pages/docs/editor.tsx` |
| 页面私有组件 | 只被一个页面使用 | `pages/docs/components/` |
| 通用组件 | 被两个及以上页面使用 | `src/components/` |

> 不足两处复用时不要提前抽象。

## 拆分参考

- 单文件接近 300~400 行时考虑拆分。
- 无业务展示片段下放为页面私有组件；复杂逻辑抽成 `useXxx` hook。
- 编辑器扩展（Tiptap Extension）放 `pages/docs/components/`，与 UI 组件分开。

## 交互与兜底

- 加载态用 `Spin` / Skeleton；空态用 `Empty`；错误由 `requestErrorConfig` 统一提示。
- 破坏性操作（删除文档、删除评论）必须二次确认（`Popconfirm` / `Modal.confirm`）。
- UI 文案中文，语气与现有页面一致。
- 可点击元素使用 antd `Button` / `Typography.Link`，不要用裸 `div onClick`。
