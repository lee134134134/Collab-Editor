# 项目结构（NON-NEGOTIABLE）

```
apps/
├── web/                        # @collab/web — Umi Max 前端
│   ├── config/                 # routes.ts / proxy.ts / config.ts / defaultSettings.ts
│   ├── mock/                   # 脚手架遗留，MOCK=none 时禁用
│   └── src/
│       ├── pages/docs/         # 文档库 index.tsx + 编辑器 editor.tsx
│       │   └── components/     # useCollabDoc / PresenceBar / CommentPanel / EditorToolbar / commentMark
│       ├── pages/user/login/   # 登录页
│       ├── services/           # docs.ts / comments.ts / self/auth.ts
│       ├── components/         # 布局与通用组件
│       ├── locales/            # 菜单文案
│       └── app.tsx             # initialState、登录态、请求拦截器
└── server/                     # @collab/server — NestJS + 原生 ws
    ├── src/
    │   ├── auth/               # JWT 登录、守卫、@CurrentUser
    │   ├── docs/               # 文档元数据 CRUD
    │   ├── comments/           # 评论 CRUD
    │   ├── collab/             # ticket / ws-server / room-manager / persistence-queue / protocol
    │   ├── db/                 # SQLite schema + 种子
    │   ├── config.ts           # 环境变量单点收口
    │   └── file-lock.ts        # 单实例锁
    ├── test/                   # vitest + integration.mjs
    └── data/                   # 运行期数据库/锁（gitignore）
packages/shared/                # DTO、常量、共享类型
scripts/e2e.mjs                 # Playwright-core 浏览器 E2E
references/                     # 旧项目工作流 submodule，禁止修改
```

## 归属约束

| 代码类型 | 必须放 | 禁止 |
|---|---|---|
| 前端 HTTP 请求 | `apps/web/src/services/` | 组件内裸调 fetch/axios |
| 前后端共享类型 | `packages/shared/src/index.ts` | 两端各复制一份 |
| 编辑器私有 hooks/组件 | `apps/web/src/pages/docs/components/` | 提前上提到全局 |
| 跨页面组件 | `apps/web/src/components/` | 散落在页面目录 |
| 后端 REST | `apps/server/src/<domain>/` | 控制器里写 SQL |
| 协同协议/房间 | `apps/server/src/collab/` | 在 REST controller 内管理 Y.Doc |
| 通用工具 | 就近模块或 `apps/server/src/utils/` | 重复实现 |
| 脚本 | `scripts/` | 散落在根目录 |

## 硬性约束

- 不新建上述之外的顶层目录；需要时先更新本文件与 `AGENTS.md`。
- `references/` 是 git submodule，禁止在其中新增/修改本项目文件。
- `apps/web/src/.umi*` 是生成目录，禁止手改；丢失后先 `max setup`。
