# 项目概述

## 项目定位

**Collab Editor** —— 类飞书在线协同文档编辑器。核心能力：文档库、CRDT 实时协同编辑、
在线状态与协同光标、富文本、评论批注。

pnpm monorepo：

| 包 | 职责 |
|---|---|
| `apps/web`（@collab/web） | React 19 + @umijs/max + antd 6 前端 |
| `apps/server`（@collab/server） | NestJS 11 REST + 原生 ws 协同服务 |
| `packages/shared`（@collab/shared） | 前后端 DTO、常量、共享类型 |

## 技术栈

- 前端：React 19、Umi Max、antd 6、antd-style、@ant-design/pro-components。
- 编辑器：Tiptap 3.32 + StarterKit + collaboration + collaboration-caret + @tiptap/y-tiptap。
- 协同：Yjs 13、y-websocket、awareness、lib0。
- 后端：NestJS 11、ws 8、jsonwebtoken、bcryptjs、better-sqlite3 13。
- 工具：TypeScript strict、Biome 2、Vitest 3、pnpm workspaces、husky + lint-staged + commitlint。

## 运行参数

| 项 | 值 |
|---|---|
| 前端 dev | `http://localhost:8001` |
| REST | `http://localhost:3000` |
| 协同 WS | `ws://localhost:3001` |
| 数据库 | SQLite `apps/server/data/collab.db` |
| 种子账号 | `admin/admin123`、`alice/alice123`、`bob/bob123` |

## 文档入口

- 命令、目录、环境变量、已知限制：根目录 `AGENTS.md`
- Claude 摘要：`CLAUDE.md`
- 快速开始：`README.md`
- 接口/WS 契约：`packages/shared/src/index.ts` 与 `apps/server/src/collab/protocol.ts`
