# 样式规范

## 技术选型

- UI 组件一律 antd 6；优先使用组件自带样式与 token，不手写重复组件。
- 组件级样式用 `antd-style` 的 `createStyles` 或同目录 CSS 文件。
- 全局样式只允许在 `apps/web/src/global.less`；`tailwind.css` 已在 `global.tsx` 引入，可按需使用。
- 编辑器样式集中在 `apps/web/src/pages/docs/components/editor.css`。

## Token 与颜色

- 颜色、圆角、间距优先取 antd token：`token.colorPrimary`、`token.borderRadius`、`token.colorText`。
- 禁止硬编码品牌色；确需固定色（如评论高亮）集中在 CSS 变量或 shared 常量。
- 深色/浅色主题变化通过 token 自适应，不要写死背景色。

## 命名与作用域

- CSS 类名 BEM：`block__element--modifier`，如 `doc-editor__header`、`comment-panel`。
- 页面私有样式放页面目录；跨页面复用样式放 `global.less` 并加注释说明原因。
- 避免 `!important`；需要覆盖 antd 时用更高特异性或 `:where()`。
- 禁止用内联 style 写复杂布局；简单动态值（宽高、颜色）可内联。

## 响应式与编辑器

- 编辑器页面高度用 `calc(100vh - 56px)` 等布局约束，避免内容区滚动穿透。
- 工具栏在窄屏可横向滚动；评论面板在窄屏可收起/覆盖。
- 协同光标/选区样式使用 `collaboration-carets__caret` 约定，不要改类名。
