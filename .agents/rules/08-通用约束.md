# 通用约束

## 语言

| 用途 | 语言 |
|---|---|
| 注释、文档、UI 文案、提交信息 | 中文 |
| 标识符、文件名、类型名 | 英文 |
| 代码关键字/API | 英文 |

## 安全

- 不提交密钥、token、数据库密码；`JWT_SECRET` 生产必须用环境变量覆盖。
- 前端不信任 localStorage 中的用户信息，以 `GET /api/auth/me` 为准。
- WS 必须校验 `Origin` 白名单与一次性 ticket；不要关闭鉴权图省事。
- 删除/更新评论、文档必须校验当前用户与资源存在性。

## 环境变量

| 变量 | 默认值 | 作用 |
|---|---|---|
| `PORT` / `WS_PORT` | 3000 / 3001 | REST / 协同 WS |
| `JWT_SECRET` | dev 默认值 | JWT 签名密钥 |
| `DB_PATH` | `data/collab.db` | SQLite 路径（相对 apps/server） |
| `COLLAB_ALLOWED_ORIGINS` | localhost/127.0.0.1:8001 | WS Origin 白名单 |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | admin / admin123 | 种子管理员 |
| `UMI_APP_COLLAB_WS_URL` | `ws://localhost:3001` | 前端 WS 地址 |

## 单实例硬约束

- 服务端启动时通过 `data/collab.lock` 防多实例；内存房间多实例会静默丢更新。
- 禁止横向扩容当前版本；部署多个实例前必须先改造为共享状态/持久化广播方案。

## 提交

- Conventional Commits（commitlint）：`feat:` / `fix:` / `refactor:` / `chore:` / `docs:`。
- 提交前 husky + lint-staged 会跑 Biome；不要用 `--no-verify` 绕过。
- 仅提交本次任务相关文件，保留其他会话工作区改动。
- 本机 git 若遇 iconv 报错：`git -c core.precomposeunicode=false ...`。
